# Working in Robot Agent Demo

This repository publishes demonstration generation and inspection. VLA training
and automatic expert-data qualification are outside the first release.
For online robot operation read `.agents/skills/dexhand-tool-use/SKILL.md`.
For read-only inspection do not launch a simulator. Quickstart executes references.
Use `.venv/Scripts/python.exe` on Windows or `.venv/bin/python` on Unix.
Keep task contracts, source provenance and unsuccessful attempts. Do not alter an
evaluator or simulator during a frozen trial. Distinguish online agent choices,
local feedback programs, calibrated references and learned controllers.
